🔬 How RheumaCare Works

RheumaCare combines machine learning, patient health tracking and data analytics to provide an educational rheumatoid arthritis support platform.

Patient information can be assessed using the machine learning model, while the analytics dashboard provides visual insights from the patient dataset.

💡 Quick Access

Use RA Assessment to enter patient parameters.

Use Patient Analytics to explore the dataset visually.

Use Health Tracker to record health observations.

📌 RheumaCare Workflow

01. Patient Data

Collect relevant patient health parameters such as RF, Anti-CCP, ESR, CRP and joint symptoms.

02. ML Assessment

The machine learning model analyzes the entered parameters and provides an educational RA-related indicator.

03. Analytics

Visualize patient information using charts for diagnosis, age, gender, inflammation and symptoms.

04. Health Tracking

Record health observations and monitor changes in symptoms over time.
