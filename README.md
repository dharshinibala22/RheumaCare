# 🩺 RheumaCare

## Rheumatoid Arthritis Analytics and Patient Support Web Application

RheumaCare is a web-based healthcare support application developed to provide rheumatoid arthritis (RA)-related assessment, patient tracking, health information, and analytics in one platform.

The application combines **Flask, SQLite, Machine Learning, and Data Analytics** to create an easy-to-use patient support system.

> **Note:** The dataset used for analytics and machine learning in this project is synthetic and is intended for educational and academic project demonstration purposes.

---

## 🎯 Project Objectives

The main objectives of RheumaCare are:

- To develop a web-based healthcare support application for Rheumatoid Arthritis.
- To provide an RA-related assessment using Machine Learning.
- To analyze patient data using Data Analytics.
- To visualize patient information through an interactive analytics dashboard.
- To provide general diet and health guidance.
- To record doctor-prescribed medicine schedules.
- To allow users to track health-related information.
- To present complex healthcare data in a simple and understandable format.

---

## ✨ Features

### 🔐 1. User Authentication

- User registration
- User login
- Secure password hashing
- Session-based authentication
- Logout functionality

---

### 🧠 2. RA Assessment

The assessment module collects selected patient-related information and uses a trained Machine Learning model to provide an RA-related prediction/indicator.

The module is designed for:

- Educational purposes
- Academic project demonstration
- Data Science application demonstration

> The prediction is not a medical diagnosis and should not replace professional medical consultation.

---

### 📊 3. Patient Analytics Dashboard

The analytics dashboard provides visual insights from the Rheumatoid Arthritis dataset.

It includes:

- Total patient count
- RA-positive cases
- RA-negative cases
- RA-positive percentage
- Age-group comparison
- Gender comparison
- Inflammatory indicators
- Joint symptoms
- DAS28 severity distribution

The dashboard uses interactive charts to make the data easier to understand.

---

### 🥗 4. Diet Guidance

The Diet module provides general educational information related to healthy lifestyle and dietary considerations.

It includes information about:

- Healthy food choices
- General dietary considerations
- Foods that may support a healthy lifestyle
- Basic health guidance

> This section is for educational purposes and does not replace advice from a qualified healthcare professional.

---

### 💊 5. Medicine Module

The Medicine module allows users to record medicine information and schedules prescribed by their doctor.

It can be used for:

- Recording medicines
- Recording prescribed schedules
- Reminder functionality
- Viewing medicine information

> RheumaCare does not prescribe medicines or change medication dosage or timing.

---

### 📈 6. Health Tracker

The Health Tracker allows users to record and monitor health-related information.

This helps users maintain their own health records within the application.

## 📊 Dataset

The project uses a **synthetic Rheumatoid Arthritis dataset** for educational and analytical purposes.

The dataset contains patient-related attributes such as:

- Patient ID
- Age
- Sex
- Smoking Status
- Family History of RA
- Rheumatoid Factor (RF)
- Anti-CCP Antibody
- ESR
- CRP
- Tender Joint Count
- Swollen Joint Count
- Morning Stiffness
- Disease Duration
- DAS28 Score
- Diagnosis

### Dataset Purpose

The dataset is used for:

- Data preprocessing
- Exploratory data analysis
- Data visualization
- Patient group comparison
- Machine Learning
- Analytics dashboard development

> The dataset is synthetic and does not represent real patient records.
